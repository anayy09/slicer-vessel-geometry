# slicer-vessel-geometry

Segment the aorta from contrast CT in 3D Slicer, clean the surface mesh in VTK,
and measure it: surface area, enclosed volume, plane cross-sections, and a
cross-sectional area profile along a VMTK centerline. Every measurement is
checked against synthetic phantoms with closed-form answers.

Scope: built in November 2026 as a hands-on learning project. Work in progress.

## Layout

| Path | Contents |
|------|----------|
| `vesselgeom/` | Pure Python + VTK + numpy geometry (no Slicer imports), tested in a plain venv |
| `scripts/` | Headless Slicer scripts, run with `$SLICER_EXE --no-main-window --python-script` |
| `tests/` | pytest on synthetic phantoms |
| `SlicerVesselGeometry/` | Slicer scripted module |
| `notes/` | Explanations of each step |

## Setup

1. Install 3D Slicer from https://download.slicer.org and the SlicerVMTK and
   SegmentEditorExtraEffects extensions.
2. Point `SLICER_EXE` at the Slicer executable and check the environment:

   ```powershell
   & $env:SLICER_EXE --no-main-window --python-script scripts\00_check_env.py
   ```

3. Standalone venv for the geometry library and tests:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements-dev.txt
   pytest
   ```

Data: the public CTACardio sample from Slicer's Sample Data module. No imaging
data is committed; everything under `data/` is regenerated by the scripts.
